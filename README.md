# Coffee Shop Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is a **Power BI dashboard** designed to analyze sales data from a local coffee shop chain.  
It provides interactive visualizations and key performance indicators (KPIs) such as **Total Sales, Total Orders, and Quantity Sold**, with comparisons over time.  
The dashboard helps stakeholders understand sales trends, identify top-performing products, and optimize store operations.

---

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard creation and data visualization  
- **DAX** – Calculations for KPIs and advanced metrics  
- **CSV/Excel** – Source data for sales transactions  

---

## 📂 Dataset
The dataset contains:
- Transaction ID, date, and time  
- Store ID and location  
- Product ID, category, type, and details  
- Unit price and quantity sold  

---

## 🔑 Key Features
- KPIs: Total Sales, Total Orders, Quantity Sold, Average Sales  
- Time Analysis: Current Month vs Previous Month comparisons  
- Sales Breakdown: By product category, type, and store location  
- Trend Analysis: Daily, weekly, and hourly sales patterns  
- Interactive visualizations with filters and drill-downs  

---

## 🚀 How to Use
1. Open **CoffeeShopSalesDashboard.pbix** in Power BI Desktop.  
2. Import your dataset (Excel/CSV) and map columns to the existing data model.  
3. Refresh the dashboard to view updated visuals and KPIs.  
4. Interact with filters, charts, and slicers to explore insights.  
5. Export as PDF or publish to Power BI Service to share.
